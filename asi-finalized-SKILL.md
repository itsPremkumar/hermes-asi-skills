## The 7-Stage Loop

1. **Understand** — Restate goal, surface assumptions
2. **Decompose** — Pick a pattern (sequential, parallel, pipeline)
3. **Analyze** — Apply 2-3 lenses (structural, causal, adversarial, etc.)
4. **Gather** — Replace assumptions with evidence
5. **Execute** — Work the plan, keep a trail
6. **Verify** — Match depth to stakes (Tiers 1-4)
7. **Reflect** — What was uncertain

## Verification Tiers

| Stakes | Depth | Bar |
|--------|-------|-----|
| Low | Self-check | Sanity check passes |
| Medium | + adversarial pass | No failure modes found |
| High | + edge cases | All edge cases checked |
| Critical | + disclosure | User told what wasn't verified |

## Decomposition Patterns

- **Sequential** — A → B → C
- **Parallel-independent** — Run concurrently, synthesize
- **Pipeline** → transform → validate → deliver
- **Divide-and-conquer** — Split by item, recombine
- **Exploratory-then-committed** — Narrow, then plan

## Analytical Lenses

| Lens | Question | Good for |
|------|----------|----------|
| Structural | Parts and connections? | Systems, code |
| Causal | What causes what? | Debugging |
| Temporal | Sequence and timing? | Planning |
| Comparative | vs similar cases? | Decisions |
| Adversarial | How could it fail? | Security |
| Counterfactual | If assumption false? | Novel problems |

## Honesty Rules

- No fabricated citations
- Gaps stated, not smoothed
- Fail visibly and gracefully

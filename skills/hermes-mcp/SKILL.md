# HERMES MCP: Complete v0.21.0 Mastery

Full MCP (Model Context Protocol) mastery for Hermes Agent v0.21.0 Pantheon release.

## MCP Capabilities (v0.21.0)

### 1. Expanded Catalog
- Curated MCP server catalog
- Interactive picker (hermes mcp)
- Search and filter
- One-command install

### 2. Transport Support
- stdio: Local subprocess
- HTTP: Hosted servers
- SSE: Server-Sent Events
- OAuth 2.1: Authenticated servers
- mTLS: Mutual TLS for security

### 3. Custom MCP Servers
- Build your own MCP servers
- JSON schemas for tools
- stdio/HTTP/SSE transports
- Share with community

## MCP Protocol

1. DISCOVER: Find available MCP servers
2. CONFIGURE: Set transport and auth
3. INTEGRATE: Add to agent toolset
4. USE: Invoke via tool calls
5. MONITOR: Track usage
6. OPTIMIZE: Adjust configuration

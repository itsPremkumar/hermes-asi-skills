# HERMES MEMORY: Complete v0.21.0 Mastery

Full memory mastery for Hermes Agent v0.21.0 Pantheon release.

## Memory Architecture

### 1. Built-in Memory
- MEMORY.md: Static facts (user preferences, project conventions, environment)
- USER.md: User model and preferences
- SessionDB: SQLite + FTS5 full-text search
- Session lineage tracking (parent/child across compressions)

### 2. Memory Providers (8+ Plugins)
- Honcho: Dialectic memory
- Mem0: Semantic search
- Supermemory: Cross-session modeling
- Hindsight: Experience replay
- Holographic: Knowledge graphs
- RetainDB: Long-term retention
- ByteRover: Context management
- OpenViking: Semantic recall

### 3. Memory-Backed Cron Jobs
- Recurring tasks with full memory access
- Memory-aware scheduling
- Per-bot routines

## Memory Protocol

### Storage
1. CAPTURE: Record important information
2. STRUCTURE: Organize by type and relevance
3. INDEX: Create retrieval paths
4. ASSOCIATE: Link to related memories

### Retrieval
1. CUE: Identify what you need
2. SEARCH: Find relevant memories
3. RECALL: Retrieve details
4. VERIFY: Confirm accuracy

### Consolidation
1. COMPRESS: Summarize key facts
2. LINK: Create semantic connections
3. PRUNE: Remove outdated info
4. REPLAY: Reactivate important memories

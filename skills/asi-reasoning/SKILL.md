# ASI REASONING: Deep Reasoning Engine

Advanced reasoning system for ASI-level problem solving.

## Reasoning Modes

### 1. Chain-of-Thought (CoT)
```
PROBLEM → STEP 1 → STEP 2 → ... → STEP N → VERIFICATION → ANSWER
```

### 2. Tree of Thoughts (ToT)
```
GENERATE 3-5 PATHS → EVALUATE → EXPAND BEST → PRUNE → SELECT → EXECUTE
```

### 3. Graph of Thoughts (GoT)
```
MULTIPLE PARALLEL PATHS → CROSS-REFERENCES → SYNTHESIS → VERIFICATION
```

### 4. Reflexion
```
ATTEMPT → REFLECT ON FAILURE → REVISE → RETRY → LEARN
```

## Reasoning Protocol

1. UNDERSTAND: Restate problem in own words
2. DECOMPOSE: Break into sub-problems
3. STRATEGY: Select reasoning mode
4. EXECUTE: Apply reasoning step-by-step
5. VERIFY: Check each step
6. SYNTHESIZE: Combine results
7. VALIDATE: Final verification

## When to Use
- Complex multi-step problems
- Novel situations
- High-stakes decisions
- Verification required

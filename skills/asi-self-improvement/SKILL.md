# ASI SELF-IMPROVEMENT: Recursive Evolution System

Advanced self-improvement for ASI-level capability growth.

## Two-Timescale Evolution (MetaSkill-Evolve)

### Fast Loop (Task Skills - What Agent Does)
```
ENCOUNTER → ATTEMPT → REFLECT → MUTATE → EVALUATE → COMMIT
```

### Slow Loop (Meta-Skills - How Agent Improves)
```
ANALYZE improvement patterns
GENERATE meta-mutations
EVALUATE meta-changes
COMMIT better improvement procedures
```

## Self-Improvement Protocol

### After Every Complex Task
1. CAPTURE execution trace
2. REFLECT on success/failure
3. EXTRACT reusable procedure
4. STORE as new SKILL.md
5. UPDATE existing skills if better approach found

### Skill Creation Triggers
- Complex task completed (5+ tool calls)
- Error recovered via non-obvious workaround
- User correction reveals better approach
- Pattern repeats 3+ times

### Mutation Operators
- Rewrite instruction step for clarity
- Add missing edge case handling
- Reorder steps for efficiency
- Add verification step
- Remove redundant step
- Replace tool with better alternative

## Guardrails
- Skills ≤15KB size limit
- Must pass test suite before activation
- Semantic drift checks
- Human review for all new skills
- All changes via PR, never direct commit

## When to Use
- After complex tasks
- When patterns repeat
- After failures
- Continuous improvement
